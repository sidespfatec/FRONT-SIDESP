# Implementação

O projeto contém frontend Angular e backend Spring Boot. O código inclui cadastro de adulto e menor, login por CPF ou e-mail, sessão e proteção de rotas. A API usa banco relacional e migrations Flyway. Consulte [BACKEND.md](BACKEND.md) e [CONTRATO-API.md](CONTRATO-API.md) para os detalhes.

As outras telas e funcionalidades podem estar em estágios diferentes. Consulte o código e as issues antes de afirmar que uma funcionalidade está pronta. Recuperação de senha, dados de saúde e preparação para produção ainda exigem trabalho e decisões da equipe. Testes registrados anteriormente estão em [VALIDACAO.md](VALIDACAO.md); eles não substituem uma nova execução após alterações.
